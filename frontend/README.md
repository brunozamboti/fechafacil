# Frontend — FechaFácil

Frontend da aplicação FechaFácil, desenvolvido com ReactJS e Vite.

A interface permite utilizar os módulos de:

- Caixas;
- Movimentações;
- Fechamentos;
- Contador de notas e moedas.

A aplicação consome a API REST do backend Spring Boot.

## Executar localmente

```bash
npm install
npm run dev
```

Por padrão, o frontend utiliza:

```text
http://localhost:8080
```

como endereço da API.

Em produção, o endereço pode ser configurado através da variável:

```text
VITE_API_URL
```

Para informações completas sobre o projeto, consulte o `README.md` localizado na raiz do repositório.
